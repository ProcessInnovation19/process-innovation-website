# Agent guidance

The `docs/` directory is the source of truth for this website.

Before major implementation or review work, read the documents in numeric order from `docs/00_VISION.md` through `docs/09_CURRENT_AP_REFERENCE.md`, then read `docs/99_SOURCES.md`.

Priorities:

1. communicate A&P as proactive, continuous IT management;
2. preserve factual accuracy of service and partner claims;
3. preserve the futuristic game-HUD interaction language;
4. favor maintainable, responsive, accessible frontend code;
5. treat items in `docs/08_OPEN_QUESTIONS.md` as unresolved until explicitly updated;
6. treat `docs/09_CURRENT_AP_REFERENCE.md` as the current baseline, not as content that must be published unchanged.

Do not infer commercial, legal or security guarantees that are not present in the project documentation.
