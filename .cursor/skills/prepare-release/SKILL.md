# Prepare Release

**Checklist:**

1. Verify branch and target version
2. Verify docs alignment
3. Verify test/readiness status
4. Verify deploy assumptions
5. Summarize release notes
6. Report task end state: CHECKPOINT ONLY | COMMIT READY | COMMIT + PUSH READY
