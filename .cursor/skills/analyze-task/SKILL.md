# Analyze Task

**Checklist:**

1. Identify goal
2. Identify affected areas
3. Identify risks
4. Identify docs to read/update
5. Propose smallest safe path
6. If APIs/libs are unfamiliar → run `research-before-code` before coding
7. For non-trivial work → short ordered plan (Superpowers-style); note verify steps
8. Prefer Ponytail ladder: reuse / stdlib / existing deps before new code
